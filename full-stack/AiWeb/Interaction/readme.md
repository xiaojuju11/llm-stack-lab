# 网络地址组成
1. 协议：http、https
2. 域名(IP)
    - 域名：www.itbaizhan.com
    - IP：192.168.1.1
3. 端口：80、443、8080
https://www.itbaizhan.com:443

除了网络地址之外，我们测试要用到的还有本地地址，本地地址是需要一个本地服务器支持：
- 本地地址
    http://localhost:80
    http://127.0.0.1:80

# 什么是 PHP？
1. PHP 是强有力的服务器端脚本语言
2. PHP 是免费的，并且使用广泛
3. PHP能够包含文本、HTML、CSS以及PHP代码，在服务器上执行，结果以纯文本返回浏览器。PHP是从C和Perl发展而来的一种非常简单的语言，但是它看上去更像Java，同时也非常灵活
