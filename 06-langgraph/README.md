# 06 - LangGraph：当流程有分支、循环和人工确认

LangChain 的链是**直线**：A 到 B 到 C。一旦需要「根据结果决定回退还是前进」「失败重试三次再交给人」「多个角色互相传递」，直线就不够了——这就是图要解决的问题。

## 目标

- 能用「状态 + 节点 + 边」描述一个流程，并说清状态该存什么、不该存什么
- 能写条件边实现分支与循环，并给它设终止条件
- 能用 checkpointer 做持久化，实现中断后恢复与多轮会话
- 能实现人工介入（human-in-the-loop）：关键节点暂停、等人确认、再继续
- 能搭一个 supervisor 模式的多 Agent 编排

## 验收标准

1. 画出你的图（节点 + 边 + 条件），能口述「输入走到输出经过哪几个节点、什么情况下回退」。
2. 实现一个会循环的图：检索 → 判断资料够不够 → 不够就改写查询再检索 → 最多 3 轮。**跑起来能看到它真的回退过**。
3. 用 checkpointer 实现中断恢复：进程杀掉后，用同一 `thread_id` 能接着跑。
4. 人工介入能真正卡住：在「发送邮件前」暂停，等命令行输入 y/n 才继续。
5. 多 Agent 版本能让 supervisor 把任务分给两个不同职责的 Agent，并汇总结果。
